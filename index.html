OnTop

A personal tool for keeping up with my routines. Consists of three parts — a daily schedule, a core section of routines on a two-week rotation, and a list of less frequent, “do when there’s time” tasks.

Built for minimal maintenance, the content lives in a GitHub gist and completions are optionally persisted cross-device in a user-supplied Supabase database.

Wrote it in ClojureScript, for my love of the language and its stability. Used agentic coding inspired by Matt Pocock’s workflow, including a glossary to align with the AI on a shared vocabulary and /grill-with-docs to hash out decisions.

Features

  • Gmail-style keyboard navigation
  • Built-in 30-minute timer
  • Hooks in nicely with my overall productivity system
